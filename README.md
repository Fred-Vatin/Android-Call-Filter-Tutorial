## Législation

Une chance est qu’en France, les numéros de démarchage sont encadrés par l’ARCEP. Il doivent utiliser un certain schéma défini [ici](https://www.arcep.fr/la-regulation/grands-dossiers-thematiques-transverses/la-numerotation.html#c8961). Ils sont labellisés tels que : ***Numéros polyvalents vérifiés (pouvant être utilisés comme numéro d’appelant par des systèmes automatisés d’appels et d’envoi de messages)***. Ainsi, ils sont facilement identifiables puisque commençant toujours par certains numéros. Et cela va bien nous arranger pour tous les bloquer.
